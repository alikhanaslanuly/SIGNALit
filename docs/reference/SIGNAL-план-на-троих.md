## 0. Что уже есть (коротко)

Работает весь путь: камера → MediaPipe (21 точка) → свои признаки и классификатор → удержание ~1 сек → калибровка / тренировка / диалог → сообщения через transport → dashboard → статус обратно пациенту. Есть Error Mode из 4 слоёв, RU/EN, озвучка, split-демо на `/`, две вкладки на `/patient` + `/dashboard`.

## 7. Что резать, если не успеваем

Порядок: свой вопрос текстом (3.5.6) → обмен между устройствами (3.8) → KZ → фильтры (3.5.5) → быстрые ответы (3.5.3) → Вариант Б калибровки (оставить А).

## 8. Правила работы в Git

- Каждая задача = отдельная короткая ветка (`feat/p1-cancel-window`, `feat/p2-dashboard-i18n`, `feat/p3-demo-mode`) и небольшой PR в тот же день. `main` всегда собирается.
- Коммиты мелкие, с префиксами `feat:`, `fix:`, `test:`, `docs:`. У каждого из троих должны быть свои коммиты.
- В PR писать: что изменилось, как проверено, известные ограничения.
- Правишь только свою папку. Нужна правка чужой: сообщение владельцу или мелкий PR ему.
- `src/contracts/` только с согласием всех троих. Новые поля стараться класть в `payload`, а не менять типы.
- Никакого `git push --force` в `main`.
